# 워드웰 — 랜덤 단어 뽑기

브라우저에서 바로 실행되는 반응형 단어 보관함과 랜덤 뽑기 앱입니다. 별도의 빌드
과정이나 서버 없이 정적 사이트로 호스팅할 수 있습니다.

## 웹사이트

[워드웰 — 랜덤 단어 뽑기](https://toki963.github.io/random-word-picker/)

## 로컬에서 사용하기

`index.html`을 최신 브라우저에서 여세요. 데이터는 IndexedDB에 저장되며, 사용할
수 없는 경우 브라우저 저장소로 전환됩니다. 입력한 단어는 현재 기기에만
저장됩니다.

## 주요 기능

- 단어와 폴더를 만들고, 수정하고, 삭제할 수 있습니다.
- 단어를 미분류로 두거나 여러 폴더에 함께 담을 수 있습니다.
- 단어와 폴더에 태그를 지정하고, AND/OR 조건으로 검색할 수 있습니다.
- 전체 보관함, 미분류 단어, 선택한 폴더나 태그 또는 폴더와 태그를 조합해
  무작위로 뽑을 수 있습니다.
- 여러 폴더를 합집합 또는 교집합으로 조합하고, 기본적으로 중복 없이 뽑을 수
  있습니다.
- 뽑은 결과를 복사하거나 텍스트 파일로 저장할 수 있습니다.
- JSON 또는 Excel 백업을 내보내거나 가져올 수 있으며, 가져올 때 기존 보관함에
  합치거나 교체할 수 있습니다.
- 밝은 테마와 어두운 테마를 지원합니다.

## 배포 방식

GitHub Pages가 `main` 브랜치의 루트 폴더를 정적 사이트로 제공합니다. 앱을
수정하면 변경 사항이 배포된 사이트에도 반영됩니다.

화면 이동은 해시 주소를 사용하고 파일 경로는 상대 경로로 지정되어 있어 프로젝트
하위 경로에서도 동작합니다.

## 데이터와 백업

JSON 백업에는 단어, 폴더, 태그, 생성·수정 시각, 단어별 폴더 ID와 단어-폴더 연결
목록이 포함됩니다. 가져오기는 항목과 연결 정보를 확인하며, 합치기에서 ID가
겹치면 새 ID를 지정합니다. 보관함을 교체할 때는 기존 데이터를 덮어쓸지
확인합니다.

Excel 백업은 `단어`, `폴더`, `연결` 시트로 구성됩니다. Excel 기능은 공식 SheetJS
브라우저 라이브러리를 불러오므로 사용 중 인터넷 연결이 필요합니다.

브라우저 데이터를 지우면 보관함도 삭제될 수 있으니, 필요하다면 백업 파일을 따로
보관하세요.
